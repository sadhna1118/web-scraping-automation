# Task Scheduler / Cron Setup Instructions

## Windows Task Scheduler
1. Open Task Scheduler (press Win + R, type 'taskschd.msc' and press Enter)
2. Click "Create Basic Task" in the right panel
3. Enter a name (e.g., "Web Scraping Automation") and description
4. Choose when to run the task (e.g., Daily, Weekly, etc.)
5. Set the time and frequency
6. Choose "Start a program" as the action
7. Configure the program/script:
   - Program/script: C:\Users\HP\anaconda3\python.exe
   - Add arguments: main.py
   - Start in: C:\path\to\web_scraping_automation
8. Check "Open the Properties dialog" and click Finish
9. In Properties:
   - Check "Run with highest privileges"
   - Set "Configure for" to your Windows version
   - Go to Settings tab and check "Run task as soon as possible after a scheduled start is missed"
   - Click OK to save

## Linux/Mac (Cron)
1. Open crontab configuration:
   ```bash
   crontab -e
   ```
2. Add the following line to run daily at 3 AM:
   ```
   0 3 * * * cd /path/to/web_scraping_automation && /usr/bin/python3 main.py >> /path/to/web_scraping_automation/logs/cron.log 2>&1
   ```
3. Save and exit (in vim: press ESC, then type :wq and press Enter)

## Verification
- Check the logs directory for execution logs
- Verify new files are created in the reports directory
- Monitor the scraper.log file for any errors

## Troubleshooting
1. If the script doesn't run:
   - Check file paths in the task scheduler/cron job
   - Verify Python is in the system PATH
   - Check the log files for errors
2. If you get permission errors:
   - On Windows: Run Task Scheduler as Administrator
   - On Linux/Mac: Ensure the script has execute permissions (chmod +x main.py)
3. For Python package errors:
   - Make sure all dependencies are installed (pip install -r requirements.txt)
   - Check that you're using the correct Python environment
